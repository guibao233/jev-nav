# 初始朝向对齐任务变体

只调整 yaw_deg，按运行器现有规则对准第一个局部目标（含拐角截断），精度为方位字段的 0.01°。起终点、pitch、参考路线、原最短路线与评估距离均继承源任务；没有改变提示词或后续目标更新。

| 任务 | 原 yaw ° | 新 yaw ° | 原目标方位 ° | 新目标方位 ° |
|---|---:|---:|---:|---:|
| turn-000 | 112.704 | -90.390 | 156.90 | -0.00 |

initial_heading 保存原朝向、生成时目标选择参数和前后目标；initial_heading_source_tasks 保存直接来源，既有 source_tasks 等规划来源字段保留。继承的 config_at_generation 仍属于源任务生成过程。

这是任务初始化条件，不是一次执行动作，不消耗动作预算。仅保证初始局部目标的水平方向对齐；不保证目标地面点在画面内、无遮挡或后续时刻一直在视野内。没有调用模型。复测需使用相同的 move_m、preview_m、sample_spacing_m、target_lookahead_m；改变这些参数后应重新生成。
