# 居中参考路线任务变体

相同起终点、初始朝向与最短距离基准，仅替换任务的 path 参考路线。原路线另存 shortest_path，SPL 仍使用原 geodesic_m。geometry 字段仍描述原最短路径。

| 任务 | 原最短长度 m | 新参考长度 m | 原/新最小额外余量 m |
|---|---:|---:|---:|
| turn-000 | 9.798 | 11.711 | 0.000 / 0.410 |

[计划对照图](index.html)。这是 CPU 规划与 NavMesh 几何验证结果，没有调用模型。

代价为距离乘以 1 + weight × exp(-额外 NavMesh 余量 / clearance_scale_m)，默认网格 0.10 m、衰减尺度 0.20 m、权重 4。尺度为软偏好，不是所有地方都保证 0.20 m 留白。网格边和简化后直连都经过原 NavMesh 验证；简化限制代价增加不超过 1%，最低余量下降不超过 0.005 m。仅支持近似平面路径，失败会明确报错，不偷偷回退到旧路线。
