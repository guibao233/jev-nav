## 当前目标为何不更新

当前 core.py:49 的规则仅在旧进度前方一个有限窗口内投影；窗口增量 max(move_m+0.15, actual_move+0.15)，通常 0.40 m。到这个局部窗口的距离须不超过 0.50 m 才接受进度。没有离路后的重接或重规划模式。

250 条日志的 reference 状态与当前 RoutePreview 重算完全一致。进度仅有以下变化：

| 决策步（从 1 开始） | 路径进度 m |
|---|---:|
| 1–88 | 0 |
| 89 | 0.0191 |
| 92 | 0.2074 |
| 93–250 | 0.3957 |

第 93 步起当前目标被下一拐角截断，固定在第一个拐角 `[-7.402807, -0.125, -6.911949]`。数值舍入导致回放反算坐标有亚毫米抖动，不代表目标更新。

“已经越过”需要区分两类情况：

- 第 96 步目标 forward=-0.075 m、left=0.668 m，距离仍为 0.672 m。只是从目标侧面经过，尚未到达目标，不能仅因 forward 变负就跳过拐角。
- 第 117 步机器人位于参考路线约 3.1254 m 处，距整条路线最近点仅 0.02139 m。到该点的 NavMesh 最短连接也是 0.02139 m、两个顶点，try_step 可直接到达，是一个真实可用的重接机会。旧局部窗口仍限制在约 0.3957–0.7957 m，因此返回距离 2.251 m 并拒绝更新。

第 115–119 步都距离后续路径不到 0.5 m，且最近连接可达。这里已经暴露出路线管理在离路后无法恢复的缺口，不能归因于 Jev 或可视化。distance_from_local_reference_m 是到旧局部窗口的距离，不是到整条路线的最近距离。

建议保持正常跟随时的有界进度，但增加显式恢复：离路后在原路径后续部分寻找同层、短连接可达的重接点；确实重新接上后更新进度。远离路径时提供可达的重接子路径，必要时再从当前位置重规划。记录恢复与重接事件。不能无条件取全局最近点，以免跨墙跳段，也不能仅放大阈值。

## 决策方向和短期历史

第一步目标在右后方：forward=-0.673 m、left=-0.330 m、bearing=-153.86°，但模型连续前进 13 次，反向移动 3.25 m。第一次碰撞在第 14 步。111 次前进中有 65 次目标 bearing 的绝对值大于 90°，即目标位于身体后半平面；这个计数包括可能的恢复移动，不能逐次都判定为策略错误，但开头持续背离路线已经很明确。

13 次碰撞中有 11 次发生前最近 5 步历史不包含碰撞。转向会挤走之前受阻的平移记录。建议在最近 5 步之外保留最近一次受阻平移及之后自身转向/成功平移状态，仍只属于机器人自身动作记忆。

## 深度摘要与语义表达

本轮前进检查为 blocked 66 次、unknown 184 次、clear 0 次。66 次 blocked 时模型全部选择转向；111 次前进全部出现在 unknown，13 次碰撞同样全部出现在 unknown。分类状态已经与动作有明显对应，但不能凭本轮证明 Jev 普遍不擅长数值。

进一步用所有像素为合法远处深度 19.8 m 的理想输入检查现有扫掠体可见性：在允许的离散俯仰 -30/-15/0/15/30/45° 下，覆盖率上限分别为 2.75% / 8.5% / 11.25% / 19.25% / 33% / 73.5%。现代码只有 coverage==1.0 才给 clear，所以本配置下在这些俯仰角上不可能得到 clear。该诊断只说明视场与采样条件，不是假定真实环境无障碍。

应拆开“是否发现下一步障碍”和“哪些区域未观测”，并给明确方向名和距离区间。不能把 unknown 直接改成“安全”，也不能硬规定 unknown 永远不准前进，否则当前可见性条件下会无法移动。

更优先补充目标的语义事实：右后方/左前方、是否背向目标、朝向误差大/已基本对齐、目标近/远。保留准确几何用于内部判断和日志，模型输入采用语义标签加关键距离，先比较同任务的数值版与混合版。

动作选项目前主要写的是运动定义。建议在各选项自己的 criteria 中加入适用条件：正常跟随时目标在后方先调整朝向，基本对齐且没有观察到阻挡再前进，恢复动作另行说明；仍让 Jev 选择，不在外部替换动作。DepthJev 公开示例采用左右方向、距离区间及动作约束，且作者报告把约束写在动作选项中比只写一般规则更能限制重复低头：https://github.com/ZJUCQR/DepthJev#-results 。这支持测试结构化描述，不构成数值/语义能力的严格对照结论。

## 后退与更居中的参考路线

可以把后退作为第七动作恢复，继续禁用左右平移。可先试 0.10–0.15 m 小步用于碰撞后拉开距离，由 Jev 主动选择；后方未观测应明确 unknown。近期走过的位置也不能无条件认定是当前后退路径，尤其转身或允许滑动之后。加入后退不能解决起始目标在后方却不转向的问题。

参考路线可以改成“长度 + 靠近障碍惩罚”的安全路线。基于现有同层 NavMesh 栅格建立距离场、加入连续靠边代价，搜索后受约束简化，并逐段验证 NavMesh 连接。不要把每个稠密栅格节点都当作必须到达的拐角。

原 NavMesh 已按约 0.10 m 半径侵蚀。额外余量可先试 0.10–0.20 m，但要检查窄通道和起终点可达性，不重复计算实体半径；优先使用柔和代价，而不是把所有窄通道直接封死。Nav2 官方也建议通过连续障碍代价场使路线倾向通道中间：https://docs.nav2.org/rolling/configuration_and_development/tuning_guide/#inflation-potential-fields 。此思路可在 jev_nav 规划层实现，不要求修改 Habitat-GS 源码。

这条路线优化的目标与纯最短距离不同，应保留原最短路线和距离作评估基准，同时保存新参考路线、长度和余量。修正路线恢复后，分别对照语义输入、后退及带余量路线，才能看清各项贡献。
