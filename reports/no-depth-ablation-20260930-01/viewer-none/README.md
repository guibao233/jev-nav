# Jev 导航可视化

来源：`/share/guiyuanze/code/habitat-gs/jev_nav/runs/smoke-depth-ablation-none-20260930-01`；共 7 幅观察。

打开 `index.html`，可播放、拖动时间轴、前后逐帧查看、调整播放间隔；键盘左右箭头也可切换。

绿色 S 起点、红色 G 终点；蓝线初始最短路径、橙线已执行轨迹、白箭头当前机器人；粉色 T 为当前目标，青色编号点为实际发送给 Jev 的前方路径点。最后终态没有新的目标。

碰撞显示红色圈叉/边框，无效动作显示黄色方框叹号/边框；RGB 和 NavMesh 同步高亮上一动作后的观察，终态也适用。地图保留已发生事件的机器人位置，并不表示精确接触点。

此目录包含页面依赖的全部图像，可以整体下载到本机。播放间隔仅控制展示，不代表实验真实耗时。`visualization.json` 保存来源和哈希；没有重跑实验或调用 Jev。

`media/` 中包含 MP4、GIF、总览和单独地图帧。
